# 🎬 2026 독립단편영화제 모바일 도록 & 상영 시간표 템플릿

공연 셋리스트 사이트(`rgb-setlist`)의 검증된 아키텍처를 바탕으로 제작된 **초경량 모바일 영화제 프로그램 웹페이지**입니다.
React, Vue 같은 프레임워크나 백엔드 서버 없이 **HTML 1개 + CSV 파일 1개**만으로 모든 상영작과 시간표를 관리할 수 있습니다.

---

## 📁 폴더 구조

```text
film_festival_template/
├── index.html               # 전체 웹사이트 (HTML + CSS + JS 통합)
├── films.csv                # 상영작 목록 및 시간표 (엑셀로 편집 가능)
├── synopsis/                # 작품별 상세 시놉시스 및 연출 의도 (.txt)
│   ├── 여름의 끝.txt
│   └── 밤의 궤도.txt
└── assets/
    ├── posters/             # 영화 포스터 (<작품명>.webp 또는 .jpg)
    └── stills/              # 상세 페이지 상단 스틸컷 (<작품명>.webp 또는 .jpg)
```

---

## 🚀 1. 상영작 및 시간표 수정 방법 (`films.csv`)

엑셀(Excel)이나 구글 스프레드시트에서 열어 자유롭게 수정한 뒤 **CSV (쉼표로 분리)** 형식으로 저장하면 웹사이트에 자동 반영됩니다.

| 컬럼명 | 설명 | 예시 |
|---|---|---|
| **작품명** | 영화의 한글 제목 | 여름의 끝 |
| **영문제목** | 영문 공식 표기 | End of Summer |
| **감독** | 감독 이름 | 김민우 |
| **섹션** | 상영 카테고리 (단편 경쟁, 초청, 애니메이션 등) | 단편 경쟁 |
| **러닝타임** | 상영 시간 | 24분 |
| **상영날짜** | 상영 일자 (필터 칩에 자동 생성됨) | 11.14 (금) |
| **상영시간** | 시작 시간 | 14:00 |
| **상영관** | 상영 장소 | 1관 (또는 CGV 3관) |
| **GV여부** | 관객과의 대화 진행 여부 (`O` 또는 `X`) | O |
| **출연** | 주요 배우 목록 | 이지은, 박서준 |
| **제작진** | 촬영, 각본, 편집 등 스태프 크레딧 | 촬영: 최동현 / 편집: 김민우 |
| **예고편URL** | 유튜브 등 트레일러 영상 링크 (없으면 비워둠) | https://youtu.be/... |

## 📖 2. 시놉시스(줄거리) 작성 방법

- `synopsis/<작품명>.txt` 형식으로 텍스트 메모장을 만들어 저장합니다.
- 예: `synopsis/여름의 끝.txt`
- 줄거리와 감독의 연출 의도를 자유롭게 작성하면 영화 상세 페이지에서 줄바꿈 그대로 깔끔하게 표시됩니다.

---

## 🌐 3. GitHub Pages로 무료 배포하기 (1분 소요)

1. GitHub에서 새 저장소(Repository) 생성 (예: `my-film-fest`)
2. 위 폴더 내 모든 파일(`index.html`, `films.csv`, `synopsis/`, `assets/`)을 커밋 & 푸시
3. 저장소 상단 **Settings** → 좌측 **Pages** 메뉴 클릭
4. **Build and deployment > Branch**를 `main` 또는 `master`로 지정하고 **/ (root)** 선택 후 **Save**
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 사이트가 즉시 오픈됩니다!
6. 완성된 주소를 [네이버 QR코드](https://qr.naver.com/) 등에서 QR 이미지로 다운받아 영화관 리플렛이나 티켓에 인쇄하면 끝납니다.
